# Todo List

HTML, CSS, JavaScript로 만든 간단한 할 일 목록 웹페이지입니다. GitHub Repository와 브랜치, 커밋, Pull Request 실습에 사용할 수 있습니다.

## 주요 기능

- 할 일 추가
- 체크박스로 완료 표시 및 취소
- 할 일 삭제
- 입력 내용이 없을 때는 항목을 추가하지 않음

## 파일 구성

```text
todo-list-github-practice/
├── index.html  # 웹페이지 구조
├── style.css   # 화면 디자인
├── script.js   # 할 일 기능
└── README.md   # 프로젝트 안내
```

## 실행 방법

1. ZIP 파일의 압축을 풉니다.
2. `index.html` 파일을 더블 클릭합니다.
3. 기본 웹 브라우저에서 Todo List를 사용할 수 있습니다.

별도의 프로그램이나 서버 설치는 필요하지 않습니다.

## GitHub 실습 아이디어

- `feature/add-counter` 브랜치를 만들어 할 일 개수 표시 기능을 추가합니다.
- 변경 사항을 commit하고 GitHub Repository로 push합니다.
- Pull Request를 생성해 변경 내용을 확인합니다.
- Pull Request를 merge합니다.
- `README.md`에 새 기능과 실습 기록을 Markdown으로 작성합니다.
